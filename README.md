# 个人作品集与创作风格API
用于存储个人原创散文作品与创作风格规范，支持AI实时读取、继承风格、生成同调性作品。

## 文档结构
- `/spec/personal-works-style-spec.md`：核心风格定义 + 完整作品集（原文+修订版）
- `/works/`：单篇作品独立存储，按标题分类
- `/api/works.json`：结构化JSON格式作品集，适配程序调用

## 创作风格
写实主义抒情散文，以私人化具象记忆为载体，克制内敛，不刻意煽情；用平实短句承载厚重情绪，擅长今昔对照、以小见大，于日常细节中见岁月、亲情与漂泊的重量。

## 调用方式
其他AI可直接通过Raw链接读取Markdown或JSON文件，继承风格与作品内容。
